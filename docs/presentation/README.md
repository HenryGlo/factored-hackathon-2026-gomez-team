# Presentation material

Draft content for the two deliverables the kickoff asks for ([submission.md](../submission.md)): a **4–6 slide deck** and a
**short video pitch**. It is text to build the deck from, not the deck itself.

| File | What it is |
|---|---|
| [slides.md](slides.md) | Six slides: headline, on-slide content, suggested visual, speaker notes and the source of every number |
| [video-script.md](video-script.md) | Narration and shot list for the video, on top of the click-by-click guide in [demo-script.md](../demo-script.md) |

Rules used here:

- Every number comes from a recorded run or a document in this repo, and its source is listed. Estimates are labelled as
  estimates. Nothing is rounded up.
- Cells marked **TBD (Saturday)** are filled from `scripts/final_eval.sh --final` and the public smoke test. Do not present
  the placeholders.
- Screenshots are in [docs/screenshots/](../screenshots/) (desktop 1440 px and mobile 390 px).
- Still open with the organizers: the submission deadline and time zone (P-01) and the maximum video length (P-02), see
  [open-questions.md](../open-questions.md). The script below is sized for about 3 minutes and marks what to cut for 2.
